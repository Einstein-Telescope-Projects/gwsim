# Workshops

Slides and hands-on materials from past `gwmock` workshops. These are a good
complement to the [Package Walkthrough](user-guide/walkthrough.md): the talks
introduce the design and scope, and the hands-on sessions walk through
generating data step by step.

!!! note

    Workshop materials reflect the `gwmock` version current at the time of
    the workshop. Commands and configuration schemas shown in older slides
    may differ from the latest release — when in doubt, the
    [User Guide](user-guide/quickstart.md) is authoritative.

## Suggested path for self-study

1. Start with the **FWO-IRI framework talk** for the package design and scope.
2. Follow the **Leuven GW Workshop hands-on** to generate your first datasets,
   alongside the [Quick Start](user-guide/quickstart.md) guide.
3. If you work on stochastic backgrounds, continue with the **SGWB workshop**
   together with the [Orchestration](user-guide/orchestration.md) page
   (signal-only SGWB configuration).
